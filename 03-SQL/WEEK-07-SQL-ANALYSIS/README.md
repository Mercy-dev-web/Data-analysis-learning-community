# Week 7: SQL Analysis

**Theme:** Asking questions and summarising data with SQL  
**Estimated effort:** 8–12 hours  
**Level:** Beginner  
**Tool:** MySQL Workbench

## Learning outcomes
By the end of this week, you should be able to:
- Filter rows using WHERE and combine conditions with AND, OR and NOT.
- Use comparison operators, IN, BETWEEN, LIKE and IS NULL.
- Sort results with ORDER BY and control output with LIMIT.
- Summarise data with COUNT, SUM, AVG, MIN and MAX.
- Group records with GROUP BY and filter grouped results with HAVING.
- Create calculated values in a query and use clear aliases.
- Translate simple business questions into SQL and explain the result.
