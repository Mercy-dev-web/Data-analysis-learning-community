## 3. Official MySQL documentation

- [SELECT statement](https://dev.mysql.com/doc/refman/8.0/en/select.html) — SELECT syntax, WHERE, GROUP BY, HAVING, ORDER BY and LIMIT.
- [Aggregate Functions](https://dev.mysql.com/doc/refman/8.0/en/aggregate-functions.html) — COUNT, SUM, AVG, MIN and MAX.
- [Comparison Functions and Operators](https://dev.mysql.com/doc/refman/8.0/en/comparison-operators.html) — comparison operators and predicates.
- [Pattern Matching](https://dev.mysql.com/doc/refman/8.0/en/pattern-matching.html) — LIKE and wildcard patterns.
- [Working with NULL Values](https://dev.mysql.com/doc/refman/8.0/en/working-with-null.html) — how missing/unknown values behave.

## 4. How to use the resources

1. Read the relevant section in the lesson first.
2. Watch the matching video section.
3. Pause and type the query in Workbench.
4. Change a condition or value and predict the result before running it.
5. Compare your output with the answer guide only after attempting the task.

Do not rush to advanced SQL. A strong analyst should be able to explain why a query returns its result, not just remember the syntax.
