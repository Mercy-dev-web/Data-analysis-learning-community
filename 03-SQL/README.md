# SQL for Data Analysis

This section teaches relational database concepts and querying. Complete Weeks 6–8 in order.

| Week | Topic | Main outcome |
|---|---|---|
| 6 | Database and SQL foundations | Understand relational databases, create a MySQL database and tables, and retrieve basic records |
| 7 | SQL analysis | Filter, sort, aggregate and summarise data to answer questions |
| 8 | SQL joins and intermediate querying | Combine related tables and solve multi-table analysis questions |

**Required output:** Project 2, a documented SQL analysis using related tables, with validated joins and interpreted results.

Start with [Week 6: Database and SQL Foundations](WEEK-06-DATABASE-AND-SQL-FOUNDATIONS/README.md).
