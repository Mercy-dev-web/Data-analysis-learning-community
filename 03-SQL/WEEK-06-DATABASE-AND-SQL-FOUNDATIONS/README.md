# Week 6: Database and SQL Foundations

**Theme:** Moving from spreadsheets to relational databases  
**Estimated effort:** 8–12 hours  
**Level:** Beginner  
**Main tool:** MySQL Community Server and MySQL Workbench

## By the end of this week, you should be able to
- Explain what a database, DBMS and relational database are.
- Identify tables, rows, columns, data types and records.
- Explain primary keys, foreign keys and one-to-many relationships.
- Describe why related data is stored in separate tables.
- Open MySQL Workbench, connect to a local server and run SQL.
- Create a database and tables, inspect their structure and insert sample records.
- Use basic SELECT queries to retrieve all columns or selected columns.

## Learning sequence
1. Read [the lesson](LESSON.md).
2. Install MySQL Server and Workbench, or use the alternative practice option in the lesson.
3. Watch the [recommended videos and readings](VIDEO-AND-READING-RESOURCES.md).
