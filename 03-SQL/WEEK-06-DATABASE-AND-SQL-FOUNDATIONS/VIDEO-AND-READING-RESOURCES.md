Use these resources in the order below. You do not need to watch every minute of a long course this week. Focus on database setup, table creation and the first SELECT queries. Save filtering, grouping and joins for Weeks 7–8.

## 2. Official MySQL documentation

- [MySQL 8.0 Tutorial](https://dev.mysql.com/doc/refman/8.0/en/tutorial.html) — an official guided introduction.
- [Creating and Using a Database](https://dev.mysql.com/doc/refman/8.0/en/database-use.html) — creating databases, tables, loading data and retrieving information.
- [CREATE TABLE statement](https://dev.mysql.com/doc/refman/8.0/en/create-table.html) — table definitions, data types and keys.
- [Foreign Key Constraints](https://dev.mysql.com/doc/refman/8.0/en/create-table-foreign-keys.html) — how foreign keys connect related tables.
- [MySQL Community Downloads](https://dev.mysql.com/downloads/) — official download location.

## 3. Extra beginner reading

- [MySQL Basics — MySQLTutorial.org](https://www.mysqltutorial.org/mysql-basics/) — approachable explanations of common SQL statements.
- [Alex The Analyst SQL Code repository](https://github.com/AlexTheAnalyst/SQL-Code) — examples accompanying some of Alex's SQL lessons.

## 4. How to study a video

1. Watch a short section.
2. Pause the video and type the query yourself.
3. Change one thing in the query and run it again.
4. Explain what changed in your own words.
5. Save your working queries in a file called `week6_practice.sql`.

Do not just watch the video and count it as practice. The goal is to write and run the SQL yourself.
