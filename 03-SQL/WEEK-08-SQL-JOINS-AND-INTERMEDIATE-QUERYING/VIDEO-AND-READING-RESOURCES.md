## 4. How to study this week

1. Draw the relationship between the tables before writing the query.
2. Identify which table should be preserved in the result.
3. Write the join and its ON condition.
4. Select only the columns needed to answer the question.
5. Run the query and inspect several rows.
6. Check row counts and totals before interpreting the result.
7. Practise writing the query again without looking at the lesson.

A useful analyst habit: never assume a JOIN is correct just because MySQL executes it without an error.
