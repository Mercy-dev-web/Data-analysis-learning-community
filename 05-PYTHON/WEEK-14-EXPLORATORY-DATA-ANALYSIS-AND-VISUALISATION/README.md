# Week 14: Exploratory Data Analysis and Visualisation

**Recommended time:** 8–12 hours | **Recommended pass mark:** 70%  
**Prerequisite:** Week 13 — Python for Data Analysis.

## What this week is about
Last week you learned to load, inspect, clean and summarise data. This week you will investigate it more deeply: distributions, unusual values, group differences, trends and relationships. You will create charts and communicate evidence-based findings.

## Learning outcomes
By the end of the week, you should be able to:
- Explain the purpose and workflow of exploratory data analysis (EDA).
- Calculate and interpret mean, median, quartiles, range and standard deviation.
- Explore numeric and categorical variables with pandas.
- Summarise data by group and over time.
- Create bar charts, line charts, histograms, boxplots and scatter plots.
- Investigate possible outliers without automatically deleting them.
- Explain why correlation does not prove causation.
- Write evidence-based insights and state limitations.

## Important notes
- Each row is an order line, not a unique customer.
- Revenue is not profit. Gross profit here is revenue minus supplied product cost only; operating expenses are not included.
- The dataset is fictional.
- A correlation does not prove causation. A boxplot flag does not mean a record must be deleted.
