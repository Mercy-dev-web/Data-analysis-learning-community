# Week 13: Python for Data Analysis

**Learning area:** Python  
**Recommended time:** 8–12 hours  
**Recommended pass mark:** 70%  
**Prerequisite:** Week 12 — Python Foundations.

## What this week is about

Last week you learned Python's building blocks. This week you will use specialist libraries to work with tabular data. You will learn the pandas DataFrame, NumPy arrays, importing CSV files, inspecting and cleaning data, selecting and filtering rows, creating calculated columns, grouping records and exporting results.

The main library this week is **pandas**. NumPy is introduced as a supporting tool for numerical work. The aim is to complete a small, repeatable analysis workflow.

## Learning outcomes

By the end of the week, you should be able to:

- Explain what a Python library is and import pandas and NumPy.
- Load a CSV file into a pandas DataFrame.
- Inspect a dataset's shape, columns, data types and summary statistics.
- Select columns and filter rows using conditions.
- Identify and handle missing values and duplicate records.
- Correct data types and standardise text.
- Create calculated columns.
- Group and aggregate data to answer business questions.
- Sort results and export a cleaned dataset.
- Explain the cleaning decisions you made and their limitations.
