## How to study the videos

1. Watch one concept at a time.
2. Pause the video and type the code yourself.
3. Change at least one value and predict what will happen.
4. Run the code and compare the result with your prediction.
5. Write down one mistake you made and how you corrected it.

**Reminder:** You do not need to memorise every Python command. You need to understand the concepts, practise using them and learn how to look up syntax when necessary.
