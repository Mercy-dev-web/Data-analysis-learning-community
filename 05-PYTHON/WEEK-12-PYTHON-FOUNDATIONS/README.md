# Week 12: Python Foundations

**Learning area:** Python  
**Recommended time:** 8–12 hours  
**Recommended pass mark:** 70%  
**Prerequisite:** Complete Weeks 1–11. No previous programming experience is required.

## What this week is about

This week introduces Python as a programming language. You will learn to write and run small programs, store values, work with common data structures, make decisions, repeat tasks and create reusable functions.

The goal is not to become an advanced software developer in one week. The goal is to understand enough Python to begin working with data confidently in Week 13.

## Learning outcomes

By the end of the week, you should be able to:

- Set up and use a Python environment and Jupyter Notebook.
- Explain what a variable is and recognise common Python data types.
- Use arithmetic, comparison and logical operators.
- Work with strings, lists, tuples, dictionaries and sets.
- Write conditional statements and loops.
- Create and call simple functions.
- Convert between common data types and interpret basic error messages.
- Build a small sales-summary program.

Do not worry about pandas, NumPy, Matplotlib or advanced data analysis this week. Those belong to Week 13 and Week 14. First become comfortable with Python's basic building blocks.
