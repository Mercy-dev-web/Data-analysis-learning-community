# Week 3 Assignment — Build a Clean Event Registration Workbook

**Assessed practical deliverable**

## Scenario

A student community is organising a career event in Ibadan. The organising team has exported registration records and needs a workbook that is easy to review, sort and filter.

You are the junior data analyst responsible for preparing the workbook structure. You are not being asked to perform advanced calculations yet. Your job is to create a well-organised and usable workbook.

## Dataset

Use [community_event_registrations.csv](practice-data/community_event_registrations.csv).

The dataset is synthetic and created for this programme. It contains fictional registrations for practice.

## Your tasks

### Task 1 — Inspect the source

1. Open the CSV file.
2. Identify what one row represents.
3. List all columns and describe them.
4. Check whether the headings are clear.
5. Note any fields that should be treated as identifiers, dates, currency or categories.

### Task 2 — Create your workbook

Create an XLSX workbook named `Week_03_Spreadsheet_Foundations_YourName.xlsx` with these three sheets:

- `Raw_Data`
- `Working_Data`
- `Documentation`

Copy the source data into Raw_Data and leave it unchanged. Copy the records to Working_Data for formatting and organisation.

### Task 3 — Prepare the working sheet

In Working_Data:

1. Use clear, consistent column headings.
2. Make sure each column contains one field.
3. Apply appropriate date formatting.
4. Apply Nigerian naira currency formatting to Attendance_Fee_NGN.
5. Adjust column widths.
6. Format the header row clearly and consistently.
7. Convert the data range into an Excel Table.
8. Name the Table `EventRegistrations`.
9. Freeze the top row.

Do not add formulas this week. Formula calculations are taught in Week 4.

### Task 4 — Demonstrate sorting and filtering

1. Sort by Department A–Z.
2. Apply a multi-level sort by Department, then Registration_Date.
3. Filter to show Pending payment records.
4. Filter to show only Ibadan venue records.
5. Clear all filters and confirm all original records are visible.

Take screenshots or record the steps you performed for your submission.

### Task 5 — Documentation sheet

On the Documentation sheet, write:
- workbook purpose,
- source filename,
- what each sheet contains,
- number of records and fields,
- formatting choices,
- any structural changes,
- any issues or limitations you noticed.

Do not invent information that is not present in the dataset.

## Required submission

Create a folder named `week-03-spreadsheet-foundations` containing:

1. `Week_03_Spreadsheet_Foundations_YourName.xlsx`
2. `README.md` — a short explanation of the workbook.
3. `screenshots/` — screenshots showing your Table, sort and filter results (optional if you can demonstrate live).

## Submission rules

- Submit your own work.
- Do not overwrite the raw data.
- Do not use merged cells in the data table.
- Do not sort one column independently from the rest of the records.
- Do not add formulas before the Week 4 lessons.
- Keep the workbook readable and simple.
- Be prepared to explain and demonstrate your work during the live session.
