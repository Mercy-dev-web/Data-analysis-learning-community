# Week 3 — Spreadsheet Foundations Exercises

Complete the tasks in Excel. Where a task asks you to explain something, write your answer in your own words.

## Part A — Spreadsheet vocabulary

1. What is a workbook?
2. What is a worksheet?
3. Explain the difference between a row and a column.
4. What is a cell?
5. What does the cell address D8 mean?
6. Explain the difference between A1:A10 and A1:D10.
7. What is the purpose of the Formula Bar?
8. What is the difference between deleting cell contents and deleting an entire row?

## Part B — Data types and formatting

For each field, suggest an appropriate data type or display format and explain your choice.

1. Student registration number: OAU/2026/0041
2. Order quantity: 15
3. Sales amount: 125000
4. Registration date: 19 November 2026
5. Customer phone number: 08031234567
6. Discount rate: 0.15
7. Payment status: Pending
8. Product weight: 2.75 kg

Then answer:
- Why should phone numbers usually be stored as text?
- What is the difference between changing a value and changing its display format?
- Why should currency columns clearly identify the currency?

## Part C — Dataset structure

A staff member prepares a spreadsheet with:
- a title in row 1,
- a blank row in row 2,
- column headings in row 3,
- staff names in column A,
- department and phone number combined in column B,
- monthly salary in column C,
- a total row after every department.

Identify at least five problems if this sheet is intended for sorting, filtering and analysis. Describe how you would restructure it.

## Part D — Practical Excel tasks

Open the supplied file `community_event_registrations.csv`.

1. Open it in Excel and inspect the columns.
2. Create a new workbook and save it as `Week_03_Spreadsheet_Foundations_YourName.xlsx`.
3. Rename the first worksheet to `Raw_Data` and preserve the original imported records there.
4. Create a second worksheet named `Working_Data` and copy the records into it.
5. Make sure the column headings are clear and each field has its own column.
6. Adjust column widths so all headings and values are readable.
7. Apply an appropriate date format to Registration_Date.
8. Format Attendance_Fee_NGN as Nigerian naira currency.
9. Format the headings consistently and use Wrap Text if needed.

12. Then use a multi-level sort: Department A–Z, followed by Registration_Date oldest to newest.
13. Filter the table to show only Pending payment records.
14. Clear the filter and show only registrations from the Ibadan venue.

17. Add a third worksheet named `Documentation` and describe the workbook, the three sheets and any formatting or structural changes you made.

## Part F — Scenario

A small business has a customer list with 2,000 records. The owner wants to see only customers in Oyo State who registered in October and whose membership status is Active.

Explain:
1. Which spreadsheet feature would you use?
2. Which columns must be present and consistently populated?
3. How would you avoid changing or deleting the other customers?
4. What would you do if dates were stored in different formats?
5. Why should you preserve an untouched copy of the source?
