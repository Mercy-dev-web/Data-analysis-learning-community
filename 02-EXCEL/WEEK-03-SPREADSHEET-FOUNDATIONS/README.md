# Week 3 — Spreadsheet Foundations

**Phase:** Excel  
**Estimated study time:** 8–10 hours  
**Level:** Complete beginner  
**Required output:** A well-structured Excel workbook built from the supplied practice dataset.

## What you will learn

- Workbooks, worksheets, rows, columns, cells and ranges.
- Enter, edit, select, copy and move data.
- Understand cell addresses and relative, absolute and mixed references conceptually.
- Format text, dates, numbers and currency without changing underlying values.
- Organise records as a clean rectangular dataset.
- Create and use Excel Tables.
- Sort and filter records safely.
- Freeze panes, find and replace, manage worksheets and save files correctly.
- Understand the difference between an Excel workbook and a CSV file.

## Required output

Create a clean, formatted workbook using the community event registration dataset. Your workbook must contain a raw-data sheet, a structured working-data sheet and a short documentation sheet. Follow the assignment instructions.

**Important:** This week introduces spreadsheet foundations. Formula functions and calculations are taught in Week 4. You may explore simple cell references, but do not skip ahead.
