**Phase:** Excel  
**Estimated study time:** 10–12 hours  
**Level:** Beginner to early intermediate  
**Required output:** A management-ready Excel sales report with PivotTables, charts and a simple dashboard.

## What you will learn

- Sort and filter records safely.
- Use number, text, date and custom filters.
- Apply conditional formatting to identify patterns and exceptions.
- Create and format PivotTables.
- Arrange fields in Rows, Columns, Values and Filters.
- Summarise data by sum, count and average.
- Create PivotCharts and choose suitable chart types.
- Design a simple Excel dashboard with key metrics, charts and clear labels.
- Write findings and recommendations supported by the data.

## Required output

Create a workbook with raw data, working data, PivotTables, charts, a dashboard and a short findings sheet. Use the fictional mini-mart dataset supplied in this folder.

**Important:** A PivotTable is a summary, not a replacement for the original records. Preserve your raw data and refresh PivotTables after changing the source.
