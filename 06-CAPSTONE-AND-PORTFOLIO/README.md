# Capstone and Portfolio

This section brings the full analysis workflow together. Complete Weeks 15–16.

**Required output:** an end-to-end capstone, a clear project README, a public or review-ready portfolio and a short presentation.

- [Week 15 — Capstone Project](WEEK-15-CAPSTONE-PROJECT/README.md): complete an end-to-end retail analysis using Excel, SQL, Python and Power BI.
- [Week 16 — Portfolio and Presentation](WEEK-16-PORTFOLIO-AND-PRESENTATION/README.md): polish your capstone, organise your GitHub portfolio, communicate findings and prepare for the next stage.

A personal website is optional. Prioritise accurate analysis, clear documentation, reproducibility and honest presentation of your contribution.
