# Career-Readiness Checklist

This checklist is a starting point, not a promise of employment. Complete the items that are relevant to the roles you are exploring.

## Portfolio and evidence

- [ ] I can share at least one complete project.
- [ ] Each public project has a clear README.
- [ ] I can explain the business question and dataset grain.
- [ ] I can describe how I checked and prepared the data.
- [ ] I can explain my calculations and validate key results.
- [ ] My charts are readable and correctly labelled.
- [ ] I have stated limitations and avoided unsupported claims.
- [ ] I can explain what I personally contributed.
- [ ] My repositories contain no credentials or private data.

## Technical foundations

- [ ] I can use spreadsheets to clean, calculate, summarise and present data.
- [ ] I can write SQL SELECT queries, filter, sort, aggregate and join tables.
- [ ] I understand keys, relationships and basic data modelling.
- [ ] I can use Power Query to prepare data.
- [ ] I can build a basic Power BI report and explain its measures.
- [ ] I can use Python basics and pandas for data inspection and analysis.
- [ ] I can select a suitable chart and explain what it communicates.
- [ ] I know how to search official documentation when I get stuck.

Do not tick a skill simply because you watched a tutorial. Tick it when you can perform a small task without copying every step.

## Communication

- [ ] I can explain a technical result in plain language.
- [ ] I can distinguish a finding from an assumption.
- [ ] I can make a recommendation and explain the evidence behind it.
- [ ] I can describe a limitation without hiding it.
- [ ] I can ask clarifying questions when a business request is unclear.
- [ ] I can present a project within five to seven minutes.

## CV and online presence

- [ ] My CV is accurate and free of invented experience.
- [ ] My project entries link to working evidence.
- [ ] I list skills I can demonstrate.
- [ ] My LinkedIn profile has a clear headline and About section.
- [ ] I have added relevant project evidence where appropriate.
- [ ] My GitHub profile links to my strongest work.
- [ ] My contact details are current and professional.

## Applying and interviewing

- [ ] I read each role description carefully before applying.
- [ ] I tailor my CV honestly to the role requirements.
- [ ] I prepare examples of problem-solving, teamwork and learning.
- [ ] I practise SQL, spreadsheet and analytical reasoning questions.
- [ ] I can walk through a project from question to recommendation.
- [ ] I research an organisation before an interview.
- [ ] I ask clear questions about the role, expectations and learning opportunities.

## A practical 30-day continuation plan

**Week 1:** Review and polish the capstone; fix broken links and documentation.

**Week 2:** Practise explaining the project; ask one person to review it and act on useful feedback.

**Week 3:** Choose one skill gap based on a role or project requirement. Complete focused practice rather than starting several unrelated courses.

**Week 4:** Build or improve one additional project using a different dataset or business question. Document the process and limitations.

## Personal reflection

Write short answers:
1. Which skill improved most during the programme?
2. Which skill still needs regular practice?
3. Which project best demonstrates your current ability?
4. What kind of business question do you want to work on next?
5. What is one specific action you will take in the next seven days?
