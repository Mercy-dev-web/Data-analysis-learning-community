# Week 15 Videos and Learning Resources

These videos support the capstone workflow. They are learning references, not instructions to copy another analyst's project. Use the NaijaGlow dataset and write your own questions, queries and conclusions.

## Alex The Analyst — recommended

1. **[Data Analyst Portfolio Project | SQL Data Exploration | Project 1/4](https://www.youtube.com/watch?v=qfyynHBFOsM)**  
   Watch the approach to exploring a dataset with SQL, checking values and documenting work. Adapt the process to the three NaijaGlow tables.

2. **[Ultimate Data Analyst Bootcamp — SQL, Excel, Power BI and Python](https://www.youtube.com/watch?v=wQQR60KtnFY)**  
   Use this as a reference when you need to revisit a tool. The video chapters include SQL (17:30), Excel (4:30:00), Power BI (8:54:00) and Python (11:06:30). You do not need to rewatch the entire bootcamp.

3. **[Full Beginner Project in Excel](https://www.youtube.com/watch?v=opJgMj1IUrc)**  
   Use the Excel project workflow as inspiration for cleaning, PivotTables and presenting results. Keep your own dataset and business questions.

4. **[Full Power BI Guided Project](https://www.youtube.com/watch?v=3u7MQz1EyIg)**  
   Use this to review how a report is assembled and formatted. Your report must use the NaijaGlow model and answer the capstone questions.

## How to use the resources

- Watch only the section that helps with the task you are doing.
- Pause the video and recreate the idea with your own files.
- If a video uses a different database or tool, focus on the analytical process and adapt the syntax.
- Never submit another creator's dashboard or code as your own work.
