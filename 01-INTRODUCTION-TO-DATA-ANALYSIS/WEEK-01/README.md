# Week 1 — Introduction to Data Analysis

Welcome to the first week. This week is about learning how analysts think before they start using tools.

## Complete the files in this order

1. [Read the full lesson](LESSON.md).
2. [Watch the recommended videos and complete the reading](VIDEO-AND-READING-RESOURCES.md).
3. [Attempt the practice exercises](EXERCISES.md).
4. [Complete the assessed problem brief](ASSIGNMENT.md).
5. [Use the answer guide to review your exercise attempts](ANSWER-GUIDE.md).

Do not open the answer guide before attempting the exercises.

## Weekly outcome

You should be able to take a vague request from a business or organisation and turn it into a clear problem brief with:
- a stakeholder and objective,
- a main analytical question,
- supporting questions,
- useful metrics,
- required data,
- scope and limitations,
- a potential decision the analysis could support.

## Completion check

Before moving to Week 2, make sure you can explain the difference between descriptive, diagnostic, predictive and prescriptive analysis and have submitted your problem brief.
