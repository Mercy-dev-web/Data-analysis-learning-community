# Week 10: Data Modelling and DAX

**Study time:** 8–12 hours | **Level:** Beginner | **Pass target:** 70%

## Learning outcomes
By the end of this week, you should be able to:
- Explain fact tables, dimension tables, grain and keys.
- Build a simple star schema.
- Create and validate one-to-many relationships.
- Explain filter direction and why many-to-many relationships need care.
- Distinguish calculated columns from measures.
- Write beginner DAX measures using SUM, COUNTROWS, DISTINCTCOUNT, DIVIDE and CALCULATE.
- Create a date table and connect it to a sales table.

## Study plan
| Session | Focus | Time |
|---|---|---:|

| 2 | Relationships and model view | 2 h |

## Prerequisite
Complete Week 9 or understand how to import and clean data in Power Query. You should also understand basic Excel calculations and tables.

**Platform reminder:** Power BI Desktop is a Windows desktop application. If you use macOS/Linux, arrange access to a trusted Windows computer or school lab.

**Submission:** A .pbix file with a working model, date table, at least six measures, and a short explanation of the model design.
