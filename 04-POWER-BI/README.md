# Power BI for Data Analysis

This section introduces learners to preparing data, modelling it and communicating insights with Power BI. Complete the weeks in order.

| Week | Topic | Main outcome |
|---|---|---|
| 9 | Power BI and Power Query | Import, clean and shape data, then create a first report |
| 10 | Data modelling and DAX | Build relationships and create reusable calculations |
| 11 | Visualisation and dashboard design | Design clear reports that answer business questions |

**Required output:** A Power BI report file (.pbix) with documented data preparation steps and clear beginner-level visuals.
