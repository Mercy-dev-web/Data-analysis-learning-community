# Week 11: Data Visualisation and Dashboard Design

**Study time:** 8–12 hours | **Level:** Beginner | **Pass target:** 70%

This week brings together Power Query, data modelling and DAX from Weeks 9 and 10. You will turn a working model into a clear report that helps a business make decisions.

## Learning outcomes
By the end of this week, you should be able to:
- Match a business question to an appropriate chart.
- Build a clear report layout with visual hierarchy.
- Format cards, charts, tables, slicers and titles consistently.
- Configure visual interactions and slicers.
- Use tooltips, drill-down and drill-through appropriately.
- Apply report themes and accessible design practices.
- Write insight statements that explain what the data says and why it matters.
- Distinguish a Power BI report from a Power BI Service dashboard.

## Prerequisites
Complete Weeks 9 and 10. You should have a working model using Sales, Products, Customers and Date tables, with measures such as Total Sales, Total Units and Unique Customers.

Use your Week 10 practice files and existing .pbix model. Do not start from scratch unless your model is broken.

**Platform reminder:** Power BI Desktop is a Windows desktop application. If you use macOS/Linux, arrange access to a trusted Windows computer or school lab.

## Deliverable
A polished, interactive, two-page Power BI report saved as `Week11_Retail_Performance_Report.pbix`, with a short written insight summary.
