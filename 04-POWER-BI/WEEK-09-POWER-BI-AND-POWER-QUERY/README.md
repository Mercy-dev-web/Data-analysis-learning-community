# Week 9: Power BI and Power Query

**Study time:** 8–12 hours | **Level:** Beginner | **Pass target:** 70%

## Outcomes
- Explain Power BI Desktop vs Power BI Service.
- Import a CSV and inspect its structure.
- Clean data using Power Query.
- Set data types, trim text, standardise labels and investigate nulls/duplicates.
- Understand Applied Steps and Close & Apply.
- Create a calculated column and basic visuals.

## Study plan
| Session | Focus | Time |
|---|---|---:|
| 1 | Power BI overview, installation and interface | 1.5 h |
| 2 | Importing data and Power Query | 1.5 h |
| 3 | Cleaning and transformation | 2.5 h |
| 4 | Close & Apply and visuals | 2 h |
| 5 | Exercises and assignment | 1.5–4.5 h |
